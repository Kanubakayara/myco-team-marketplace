# Security Policy

Плагіни Claude Code виконуються з правами користувача, ізольованого середовища немає.
Тому кожен хук, MCP-сервер і скрипт у цьому репо — код, який проходить review.

## Підтримувані версії

| Плагін | Підтримується |
|---|---|
| `my-toolkit` 1.x | так |
| `my-toolkit` < 1.0 | ні |

## Як повідомити про вразливість

1. **Не створюйте публічний issue.** Скористайтеся GitHub → Security → *Report a vulnerability*
   (private advisory) або напишіть на freezonexhome@gmail.com.
2. Укажіть: плагін і версію, компонент (hook / command / skill / MCP), кроки відтворення,
   очікуваний вплив.

## SLA

| Етап | Строк |
|---|---|
| Підтвердження отримання | 2 робочі дні |
| Оцінка та план | 5 робочих днів |
| Виправлення critical / high | 7 днів |
| Виправлення medium / low | наступний плановий реліз |

Після виправлення — patch-реліз, запис у `CHANGELOG.md` і GitHub Security Advisory.

## Чеклист review для PR

- [ ] Хуки: вузький `matcher` (не `.*`), немає мережевих викликів, зрозумілі exit-коди.
- [ ] MCP-посилання: лише відомі сервери, без секретів у конфігу.
- [ ] `bin/` і скрипти: прочитані повністю, без завантаження коду з мережі.
- [ ] Змінні оточення: лише імена, жодних значень і токенів у репо.
- [ ] Мережеві виклики: перелічені в README плагіна.
- [ ] Залежності: без відомих CVE.
